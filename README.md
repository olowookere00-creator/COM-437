# Project Activity Submission 3: Personal Safety & Security Assistant
**Week 4 Project Update**

## I. Project Description

**A. App Name:** Personal Safety & Security Assistant

**B. Purpose:** Develop an Android mobile application that helps users improve their personal digital security and cybersecurity awareness.

**C. Target Users:** Students, employees, and everyday smartphone users.

**D. Overall Goal:** Provide users with simple tools and educational information to identify common cybersecurity risks and practice safer online habits.

## II. Problem Addressing

A. Many users are unaware of common cybersecurity threats.

B. Users may have difficulty identifying phishing messages, suspicious links, and weak passwords.

C. Cybersecurity information can be difficult for beginners to understand.

D. The application will provide easy-to-understand security guidance and tools in one convenient location.

## III. Platform and Development Environment

A. Primary platform: Android mobile devices.

B. Development environment: Android Studio.

C. Programming language: Java or Kotlin, depending on the final implementation.

D. Operating system: Android.

E. The application will be designed to work on commonly used Android smartphones.

## IV. Front-End and Back-End Support

### A. Front End

1. User interface and navigation.
2. Home screen and dashboard.
3. Cybersecurity tips and educational content.
4. Password-strength checker.
5. Phishing-awareness quiz.
6. Accessible and easy-to-understand visual design.
7. Clear feedback messages for user interactions.

### B. Back End

1. Process user input.
2. Evaluate password-strength criteria.
3. Manage quiz questions, answers, and results.
4. Store quiz results or user preferences when necessary.
5. Validate user input and handle errors.
6. Support future application updates and improvements.

## V. Planned Application Functionality

A. Users will be able to navigate the application's main menu.

B. Users will be able to review cybersecurity tips.

C. Users will be able to check password strength using security criteria.

D. Users will be able to complete a short cybersecurity awareness quiz.

E. The application will provide feedback based on quiz responses.

F. Users will be able to view their quiz scores.

G. The application will recommend ways to improve cybersecurity habits.

H. The application will validate input and display appropriate messages when errors occur.

I. Password checking will be performed locally where possible. Users will be advised not to enter their actual account passwords into the application.

## VI. Design and Wireframes

### A. Home Screen

1. Application title and logo.
2. Navigation menu.
3. Security tools.
4. Cybersecurity tips.

### B. Password Checker Screen

1. Password input field.
2. Password-strength indicator.
3. Security recommendations.
4. Input validation and appropriate feedback.

### C. Cybersecurity Quiz Screen

1. Question display.
2. Multiple-choice answers.
3. Submit or Next button.
4. Progress indicator.

### D. Results Screen

1. Overall quiz score.
2. Correct and incorrect answers.
3. Recommended security improvements.

### E. Basic Navigation Flow

- Home → Security Tools → Password Checker
- Home → Cybersecurity Quiz → Questions → Results
- Home → Security Tips → Educational Information
