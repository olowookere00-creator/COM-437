# COM-437
Android cybersecurity awareness application project
Project Description

A. App Name: Personal Safety & Security Assistant B. Purpose: Develop a mobile application that helps users improve their personal digital security and awareness. C. Target Users: Students, employees, and everyday smartphone users. D. Overall Goal: Provide users with simple tools and information to identify common cybersecurity risks and practice safer online habits.

II. Problem Addressing

A. Many users are unaware of common cybersecurity threats. B. Users may have difficulty identifying phishing messages, suspicious links, and weak passwords. C. Cybersecurity information can be difficult for beginners to understand. D. The app will provide easy-to-understand security guidance and tools in one location.

III. Platform

A. Primary Platform: Android mobile devices. B. Development Environment: Android Studio. C. Programming Language: Java or Kotlin. D. Operating System: Android. E. The application will be designed for compatibility with commonly used Android smartphones.

IV. Front-End and Back-End Support

A. Front End

    User interface and navigation.
    Home screen/dashboard.
    Security tips and educational content.
    Password-strength checker.
    Phishing-awareness questions.
    Simple and accessible visual design.
B. Back End


1. Store user preferences and application data.
2. Process user inputs.
3. Manage security quiz results.
4. Provide data storage when required.
5. Support future application updates and features.

V. Functionality

A. Users will be able to navigate through the application's main menu.
B. Users will be able to review cybersecurity tips.
C. Users will be able to check the strength of a password.
D. Users will be able to complete a short cybersecurity awareness quiz.
E. The application will provide feedback based on quiz responses.
F. Users will be able to view their results.
G. The application will provide recommendations for improving cybersecurity habits.
H. The application will validate user input to reduce errors.

VI. Design and Wireframes

A. Home Screen
1. App title/logo.
2. Navigation menu.
3. Security tools.
4. Cybersecurity tips.

B. Password Checker Screen
1. Password input field.
2. Password-strength indicator.
3. Security recommendations.

C. Cybersecurity Quiz Screen
1. Question display.
2. Multiple-choice answers.
3. Submit/Next button.
4. Progress indicator.

D. Results Screen
1. Overall score.
2. Correct and incorrect answers.
3. Recommended security improvements.

E. Basic Navigation Flow

  Home → Security Tools → Password Checker  
  Home → Cybersecurity Quiz → Questions → Results  
  Home → Security Tips → Information
